# 📦 Manisha Electronics - Stock & Billing System

**A complete desktop-based web application for managing inventory and generating GST invoices.**

---

## 🚀 Features

- 📊 **Dashboard** – View today's sales, invoice count, and pending dues
- 📦 **Product Management** – Add, edit, delete products with stock tracking
- 🧾 **Create Invoice** – Add customer details, items, GST (5/12/18/28%), and track payments
- 📋 **Invoice History** – Search, view, print, and delete invoices
- 🟡 **Due Invoices** – Track pending payments and record payments
- 🌙 **Dark Mode** – Toggle between light and dark themes
- ➕ **Floating Action Button** – Quick access to create invoices from any page

## ⚙️ How to Run

### 1. Start MySQL (XAMPP)
- Open XAMPP Control Panel
- Click **Start** next to MySQL

### 2. Run Backend
- Open VS Code
- Open folder: `C:\Users\ASUS\SockManagement\StockManagement`
- In terminal, run: `mvn spring-boot:run`

### 3. Run Frontend
- In terminal: `cd frontend`
- Run: `npm install`
- Run: `npm start`

### 4. Open Browser
- Go to: `http://localhost:3000`
